int main(int argc, char **argv)

	int n;

ELF File: Executable and Linkable format. Defines a program at rest on disk, and defines its execution. Used on Linux systems.
- What does it contain
	- It contains how it should be loaded and executed.
	- The other is more sematic and what the information in it contains.
- Program Headers
	- They can be read with `readelf
	- `INTERP` defines the library that should be used to load this ELF into memory
	- `LOAD` defines a part of the file that should be loaded into memory
	- You can run an ELF file with just headers though it would be broken.
- Section Headers
	- A different view of the ELF with useful info for introspection, debugging, and more. Contains a lot more sematic information.
	- `.text` Executable code of your program
	- `.plt`/`.got` used to resolve and dispatch library calls.
		- At runtime it doesn't care about the name just the location of the library to call.
	- `.data` used for pre-initialized global writable data
		- Used if your C code has a hard-coded array
	- `.rodata` used for global read-only data
		- For example the `HAHAH!` in our `cat` program will be stored here.
	- `.bss` used for uninitialized global writable data
- Symbols
	- ELFs have symbols or names that help dynamically loaded libraries find libraries, resolve function calls into the libraries and more.
- Interacting with your ELF
	- `gcc` to make the elf
	- `readelf` to parse the headers
	- `nm` can be used to read the symbols, 
		- `nm -D cat` will look at all the dynamic imports
		- `nm -a cat` will look at all the symbols
	- `patchelf` is a cool utility to mess with the elf in different ways
	- `objcopy` will allow you to export mess with then import different sections and decompile files.
		- `objcopy --dump-section .rodata=cat.hahah cat` will dump out the string from our `cat` implementation.
		- We could use `vi -b ./cat.hahah` for example to change `HAHAH` to something like `Hello` we can then use `--update-section` and modify our binary to run the new code.
		  `objcopy --update-section .rodata=cat.hahah cat` running `cat` after this will now show `Hello!` instead
		- We can use `objcopy` for help to write shellcode as well in later modules.
	- `strip` will take all the symbols out of the program.
	- [Kaitai Struct](https://ide.kaitai.io/): Web based program to look at the structure of files.
PE File: Portable executable used on Windows.
