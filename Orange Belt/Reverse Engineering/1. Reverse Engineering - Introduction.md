What is reverse engineering? 

Engineering is the creation of a program you start with an idea, code it, compile it then you run it.

Compilation takes out the comments, variable names (turn into memory locations), loss of function names, type information, algorithms can be optimized out.  Reverse engineering is the process of reobtaining these things.

Engineering tools:
- IDE
- gcc
- strings
- strip

`cpp` will show the intermediary code ready for assembling from the c code.
`gcc` can be forced to compile with intel using the `-masm=intel` flag on compilation. We can pass the `-S` flag to allow for the code the be compiled but not assembled and linked.
```
cat > hello.c << 'EOF'
#include <stdio.h>

void say_hello(char *name)
{
        printf("Hello %s\n", name);
}

int main()
{
        // this is a varible to hold my name
        char my_name[1024];
        scanf("%1000s", my_name);
        say_hello(my_name);
}
EOF
cpp ./hello.c > hello-preprocessed.c
gcc -S -masm=intel hello-preprocessed.c
gcc -o hello hello-preprocessed.s
```
