# Saving Caller-Saved Registers

When calling a function it will use certain registers for its own work. Caller-saved registers may be freely overwritten by any function you call. If a value is in one of these after a call its the callers job to save it then restore it afterwards.


| Category     | Registers                                                       |
| ------------ | --------------------------------------------------------------- |
| Callee-Saved | `RBX`, `RBP`, `R12`, `R13`, `R14`, and `R15`                    |
| Caller-Saved | `RAX`, `RCX`, `RDX`, `RSI`, `RDI`, `R8`, `R9`, `R10`, and `R11` |
