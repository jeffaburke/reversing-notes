Ok so I clarified the operations happening here in a very beautiful drawing. If we can get the right key past this operation, we will then receive the flag.

![](Attachments/Pasted%20image%2020260928170715.png)

Now we must reverse these operation's which I will do so in a script so we can hopefully obtain the correct key. 

`bit_bender_invertor.py`

```python
from pwn import p64

def inverse(expected_output):
    result = []
    for i in range(len(expected_output)):
        result.append(reversed_operation(expected_output[i]))
    return result

def reversed_operation(byte):
    return (((byte >> 2 | byte << 6) & 0xFF) - 0x21) & 0xFF

def bit_bender_inverse():
    expected_output_0 = inverse(p64(0x4d6169726d424a68))
    expected_output_1 = inverse(p64(0x5a497856435a456c))
    result = expected_output_0 + expected_output_1
    return bytes(result)
    
def main():
    print(bit_bender_inverse().hex())

if __name__ == "__main__":
    main()
```

In our script above we do the inverse of the operation in the `bit-bender` file. We start by `OR`ing together the two bytes doing the inverse of the shifts in the original program. We make sure to `AND` each result by `0xFF` to get the least significant byte. We then subtract `0x21` and once again `AND` the result. We have a loop which will compute it over each segment. We keep the segments separate to account for little-endian fun-ness. We then concatenate the two lists which are returned by the `inverse` function and return it.

Assuming our above script is correct (it wasn't the first couple times I tried), we can combine our script with `ipython` to get the solution.

```python
from bit_bender_invertor import bit_bender_inverse
from pwn import *
context.binary = "/home/kali/reversing/yellow-belt/reverse-engineering/bit-bender"
p = context.binary.process()
p.send(bit_bender_inverse())
print(p.read().decode('utf-8'))
```

### Scripting the Solution

This one could use a script. 

`bit_bender_solution.py`

```python
from pwn import context
from bit_bender_invertor import bit_bender_inverse
from re import search

context.binary = "/challenge/bit-bender"

p = context.binary.process()
p.send(bit_bender_inverse())

match = search(r"pwn\.college\{[^}]*\}", p.readall().decode())
    
if match:
    print(f"Flag: {match[0]}")
else:
    print(f"Flag not found :( give it another go.")
```
