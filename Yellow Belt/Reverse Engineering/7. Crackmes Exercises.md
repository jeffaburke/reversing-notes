Ok so I clarified the operations happening here in a very beautiful drawing. If we can get the right key past this operation, we will then receive the flag.

![](Attachments/Pasted%20image%2020260928170715.png)

Now we must reverse these operation's which I will do so in a script so we can hopefully obtain the correct key. 

`bit_bender_invertor.py`

```python
from pwn import p64

def inverse(expected_output):
    result = []
    for i in range(len(expected_output)):
        result.append(reversed_operation(expected_output[i]))
    return result

def reversed_operation(byte):
    return (((byte >> 2 | byte << 6) & 0xFF) - 0x21) & 0xFF

def bit_bender_inverse():
    expected_output_0 = inverse(p64(0x4d6169726d424a68))
    expected_output_1 = inverse(p64(0x5a497856435a456c))
    result = expected_output_0 + expected_output_1
    return bytes(result)
    
def main():
    print(bit_bender_inverse().hex())

if __name__ == "__main__":
    main()
```

In our script above we do the inverse of the operation in the `bit-bender` file. We start by `OR`ing together the two bytes doing the inverse of the shifts in the original program. We make sure to `AND` each result by `0xFF` to get the least significant byte. We then subtract `0x21` and once again `AND` the result. We have a loop which will compute it over each segment. We keep the segments separate to account for little-endian fun-ness. We then concatenate the two lists which are returned by the `inverse` function and return it.

Assuming our above script is correct (it wasn't the first couple times I tried), we can combine our script with `ipython` to get the solution.

```python

from pwn import *
context.binary = "/home/kali/reversing/yellow-belt/reverse-engineering/bit-bender"

```

`substitution_sorcery_decipher.py`

```python
from pwn import p64

def lookup_substitution(expected_output: bytes) -> list[int]:
    lookup_bytes = bytearray.fromhex("56620055611a172a7b3b042e594d475c086e3d5a5033141e2170255d7c0777027f0b1d1b72632c680c483a7378114f37014230066c27764c7a15645b24380d5e4054341f5103130e742652096b324a4466676d22796a104b39711c2f3c16432805532b23293e604e0f2d20125f754557583646317d697e3549193f18416f650a")
    sub_index_list = []
    for byte in expected_output:
        sub_index_list.append(lookup_bytes.find(byte))

    return sub_index_list

def substitution_sorcery_index_list() -> bytes:
    expected_output_0 = lookup_substitution(p64(0x63675168646a4976))
    expected_output_1 = lookup_substitution(p64(0x757141444e694573))
    result = expected_output_0 + expected_output_1
    return bytes(result)

def main():
    print(substitution_sorcery_index_list().hex())

if __name__ == "__main__":
    main()
```

Once we create our little lookup program (which I have no idea why I added the return types and argument types, I honestly remembered the feature as I started the script, just helps with readability but comments are too much). We take the output of the `d` variable and place it in a byte array which we can then use `find` to get the index of a given `byte` which is pulled from the `expected_output`. We take little-endianness into account using `pwntools` `p64` function. We then return them as bytes so we can use it later :).

## Monstrous Mangler (Easy)

### Initial Exploitation

#### Static Analysis

For this one I just went through the program looked at the strings that were print and did the reverse nothing special.

Moving backwards:
1. Swap `3` and `17`
2. Sort
3. Reverse

#### Solving the Challenge

Now we can compile a script which will do all the above things. This script should be able to help with anything we see in the future so long as we identify what is happening.

`monster_helper.py`

```python
def reverse(arr: bytearray) -> bytearray:
    return bytearray(arr[::-1])

def swap(arr: bytearray, ind_1: int, ind_2: int) -> bytearray:
    arr[ind_1], arr[ind_2] = arr[ind_2], arr[ind_1]
    return arr

def sort(arr: bytearray) -> bytearray:
    return bytearray(sorted(arr))

'''
Turns out we can simplify this process a bit... wish I knew this last challenge but hey now we know
'''
def xor_arr(arr: bytearray, xor_key: bytearray) -> bytearray:
    return bytearray(b ^ xor_key[i % len(xor_key)] for i, b in enumerate(arr))

def solve_chal():
    data = bytearray.fromhex("40414c8e4f59595e5f8182868b8b8b8c8c4c8f8f9293959798999ee7e9edeff0f4f8f9fa")

    data = swap(data, 3, 17)
    data = sort(data)
    data = reverse(data)
    data = xor_arr(data, bytearray.fromhex("f8f6359f"))
    data = swap(data, 17, 23)
    data = reverse(data)
    data = swap(data, 12, 32)
    
    return data

if __name__ == "__main__":
    print(solve_chal().hex())
```
