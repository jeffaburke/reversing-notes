# Reverse Engineering - Static Tools

## Static Tools

In reverse engineering, analyzing a program at rest/not running. Looking at what is in the binary not necessarily what it does when it is getting work done.

## Simple Stuff

[**kaitai struct**](https://ide.kaitai.io) File format parser/explorer.

**`nm`**: Lists symbols used/provided by ELF files.

**`strings`**: dumps ASCII (and other formats) strings found in a file.

**`objdump`**: Simple disassembler

**`checksec`**: Analyzes security features used by an executable.

## Advanced Disassemblers

Considered the state-of-the-art tools for disassembling.

### Commercial

**IDA Pro**: The "gold standard" of disassemblers.

**BinaryNinja**: IDA's main commercial competitor.

### Free

**Binary Ninja Cloud**: A version of Binary Ninja that runs in your browser.
