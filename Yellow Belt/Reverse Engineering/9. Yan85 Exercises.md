#### The Basics

Looking into the High Level Code, There is a bunch of functions here that seem to define different things within this language. 

We see a whole bunch of `interpret` calls. These seem to be interpreter instructions.
- `IMM`: The `interpret_imm` function calls `write_register` passing `arg2` which is the register name then `arg3` which is a 64-bit unsigned integer. So this sets the register values.
- `ADD`: Take the value of the two registers and store it in the first register.
- `STK`: If two arguments are passed push to the stack, are one argument is passed pop from the stack. Seems that you could both push and pop in the same call.
- `STM`: Set the first argument equal to the address of the second argument. Set Memory?
- `LDM`: Inverse of `STM`, set the first argument equal to the address of the fist argument. Load Memory?
- `CMP`: Checks if argument 1 is < > == != AND (arg1 != 0 && arg2 != 0) to argument 2 then it set the flags accordingly. Importantly this checks all these cases not just one.
- `JMP`: **Don't quite understand this one yet**, first argument is flags, second is a register.
- `SYS`: Syscall, see table below.

Registers:
- `a` / `0x8`: Syscall argument 1, GPR `arg1 + 0x100`
- `b` / `0x40`: Syscall argument 2, GPR `arg1 + 0x101`
- `c` / `0x10`: Syscall argument 3, Counter, GPR `arg1 + 0x102`
- `d` / `0x4`: GPR `arg1 + 0x103`
- `s` / `0x2`: Stack pointer, `arg1 + 0x104`
- `i` / `0x20`: Instruction pointer, `arg1 + 0x105`
- `f` / `0x1`: Flags `arg1 + 0x106`

Syscalls:
- `0x10`: Read memory, read the given memory via a register.
    - `a` = `fd`
    - `b` = location of `buf`
    - `c` = count
- `0x20`: Write the given memory, via the register location.
    - `a` = `fd`
    - `b` = location of `buf`
    - `c` = count
- `0x8`: Sleep
- `0x2`: Open
- `0x4`: Exit

I won't explain analysis steps for this, but the original value is `46 12 db ad 7c 6e 93 47 8f`. The final input is modified by this key `a3 45 95 90 2b a1 99 9f ce`. `sub_transcend_easy.py`

```python
a = bytearray.fromhex("46 12 db ad 7c 6e 93 47 8f")
b = bytearray.fromhex("a3 45 95 90 2b a1 99 9f ce") 

for i in range(len(a)):
    a[i] = (a[i] - b[i]) & 0xff

for x in a:
    print(f"\\x{x:x}", end='')
```

### The Decompilation Process

With the raw code we can now put it into a python file and begin our disassembler.

```python
code = bytearray.fromhex("b84002010840010440ff0202020840020440080001040001080808040408040810000401000801150202020204ff02020201400002020201100302020202040102010040013008026404020901020202024002400200010140020001020102104b02020201049b0202020c040800010400010100010001010004010008011740020800010400010100010104022004404b02020200014502020200015902020200013a02020200012002020200010501020108020204200001010004010008010800010400010100013004020b01020008020201200001010004010008012440020104022004404302020200014f02020200015202020200015202020200014502020200014302020200015402020200012102020200012002020200015902020200016f02020200017502020200017202020200012002020200016602020200016c02020200016102020200016702020200013a02020200010a02020200011401020108020204202f02028001020201806602028101020201806c0202820102020180610202830102020180670202840102020180000202850102020180800802000402020820000402200440ff01020008020208400201200004022004400001020201400108020204200008020010200104022004404902020200014e02020200014302020200014f02020200015202020200015202020200014502020200014302020200015402020200012102020200010a02020200010b0102010802020420010802001020370202620102020180c30202630102020180110202640102020180720202650102020180900202660102020180610202670102020180ec02026801020201803d0202690102020180c202026a01020201804b02026b01020201807e02026c01020201802b40020000")

REG = {1: 'c', 2: 'd', 4: 'b', 8: 'a', 0x10: 'f', 0x20: 's', 0x40: 'i'}
SYS = {1: 'read_memory', 2: 'read_code', 4: 'write', 0x20: 'sleep', 8: 'open', 0x10: 'exit'}
OPS = [(2, 'imm'), (0x40, 'add'), (1, 'stk'), (0x80, 'stm'), (8, 'ldm'), (0x10, 'cmp'), (4, 'jmp'), (0x20, 'sys')] # These have to be in order from how they are in the interpreter due to the ANDing funkiness
CON = {8: '<', 4: '>', 1: '==', 2: '!=', 0x10: '== 0'}
reg = lambda x: REG.get(x, 'NONE' if x == 0 else f'?{x:#x}') # NONE is needed for the stk command

INST_LEN = 3 # In case it gets changed later which I totally expect to happen

for n in range(len(code) // INST_LEN):
    current_rip = n * INST_LEN
    next_rip = current_rip + INST_LEN
    inst_arg2, inst_arg1, inst_opcode = code[current_rip:next_rip]
    
    instructions = []
    
    # We need to loop through all the OPCODE values ANDING against the current instruction OPCODE
    for bit, name in OPS:
        if bit & inst_opcode:
            if name == 'imm':
                # Add character interpretation (Not set on this kinda annoying when not needed)
                ascii_char = f"\t'{chr(inst_arg2)}'" if 0x20<=inst_arg2<0x7f else ''
                instructions.append(f"imm {reg(inst_arg1)} = {inst_arg2:#04x}{ascii_char}")
            elif name == 'add':
                instructions.append(f"add {reg(inst_arg1)} += {reg(inst_arg2)}")
            elif name == 'stk':
                instructions.append(f"stk push {reg(inst_arg2)} / pop {reg(inst_arg1)}")
            elif name == 'stm':
                instructions.append(f"stm *{reg(inst_arg1)} = {reg(inst_arg2)}")
            elif name == 'ldm':
                instructions.append(f"ldm {reg(inst_arg1)} = *{reg(inst_arg2)}")
            elif name == 'cmp':
                instructions.append(f"cmp {reg(inst_arg1)} {reg(inst_arg2)}")
            elif name == 'jmp':
                c = ' | '.join(v for k, v in CON.items() if inst_arg1 & k) or f'{inst_arg1:#x}'
                instructions.append(f"jmp if {c} dest: {reg(inst_arg2)}")
            elif name == 'sys':
                s = ' | '.join(v for k, v in SYS.items() if inst_arg1 & k) or f'{inst_arg1:#x}'
                instructions.append(f"sys {s} -> {reg(inst_arg2)}")
                
    print(f"{n:02x}: {inst_arg2:02x} {inst_arg1:02x} {inst_opcode:02x}   " + ('; '.join(instructions) or '???'))
```
